# ma belle — наша маленькая вселенная ❤️

Персональный романтический сайт на HTML, CSS и JavaScript.

## Как открыть
1. Распакуй `ma_belle_love_story.zip`.
2. Открой папку в VS Code.
3. Открой `index.html` в браузере или запусти через Live Server.

## Что внутри
- Тёмный романтический дизайн с луной, звёздами и плавающими эффектами.
- Адаптация под телефон.
- Хронология с датами и фразами из экспорта переписки.
- Интерактивный словарь ваших словечек.
- Галерея из пяти фото; фото сжимаются и сохраняются в локальном хранилище браузера.
- Письмо в твоём разговорном стиле.
- Секретное сообщение и кнопка с сердечками.
- Звуковые сигналы, включаемые вручную.

## Важно
- Фото хранятся в браузере на устройстве, где их добавили. Они не встраиваются автоматически в сайт для других людей.
- Если отправляешь сайт девушке по ссылке, добавь фотографии в папку проекта и измени галерею в `index.html`, чтобы они были доступны всем.
- Шрифт загружается из Google Fonts, поэтому для него нужен интернет. Без интернета сайт всё равно работает с системными шрифтами.
- Сайт не отправляет сообщения и не загружает переписку куда-либо.
